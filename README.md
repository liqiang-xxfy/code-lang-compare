# 编程语言对照手册

多语言并排对比工具。选一门**基准语言**，勾选若干**对比语言**，按知识点并排对照各语言的代码与差异。默认基准为 JavaScript。

- **基准语言（3 门）**：JavaScript / Python / Java
- **对比语言（9 门）**：Go / Rust / TypeScript / ArkTS / Kotlin / Swift / Dart / C++ / PHP

## 使用方式

1. **选基准语言** —— 基准是参照系，三个基准各有一套内容与独立地址。
2. **勾选对比语言** —— 四个章节型板块是多选（勾几门并排几门）；速查三兄弟是单选（一门目标语言 = 一篇文章）。
3. **逐格看** —— 一个知识点 × 一门语言 = 一格，包含该语言的代码、写在其注释里的差异说明，以及一枚等价徽章。

## 板块与章节

下表第三列是**以 JavaScript 为基准时**的章（换成别的基准，章名与分组不同）。

| 板块 | 回答的问题 | 章（JS 基准） |
| --- | --- | --- |
| 基础表达 | 能读懂对方在写什么 | 变量、作用域与提升 / 类型与值 / 运算符与相等 / 控制流 / 函数与参数 / 字符串与容器 |
| 数据与抽象 | 能照着改写 | 模块与导入 / 错误处理 / 集合与容器 / 迭代与生成 / 对象与类 / 抽象与多态 |
| 语言机制 | 换语言必须重学的机制 | 类型系统 / 泛型与参数化 / 内存与所有权 / 并发 / 异步 / 元编程 |
| 工程实践 | 换工具、概念不变的部分 | 包管理与依赖 / 构建与工具链 / 测试 |
| 迁移陷阱 / 速语词典 / 迁移学习路线 | 按症状与术语反查 | 不设章，按方向组织（JS 出发有 11 个方向） |

同一批知识点在不同基准下落在不同的章。例如「继承」在 JS 视角下属于「对象与类」章，
在 Python 视角下属于「类与数据模型」章，而内容只写一份。

## 一个格子的实际内容

以「空值表示」这个知识点为例，下面是其中 3 格的原文。

```js
// JavaScript —— 作为基准列时，读它自己的定义
let a;               // @note undefined —— 声明了但还没有值
const b = null;      // @note null —— 有意表示「这里是空的」
a == b;              // @note! true —— 松散相等把两者视为一样
```

```python
# Python —— 作为对比列时，读它和当前基准的差异
a = None             # @note 唯一的空值
d["missing"]         # @note! KeyError —— 下标访问不返回 None
```

```go
var x int             // @note 未初始化的变量是零值 0，不是「未定义」
var m map[string]int  // @note nil map 不能写，写了会 panic
```

以 JavaScript 为基准时，这一格在 11 门对比语言中的徽章分布为 **10 门 `≠`、1 门（PHP）`≈`**。
基准换成 Python 后，同一格读到的说明随之改变。

徽章四态：

| 徽章 | 含义 |
| --- | --- |
| `=` | 同构，语义与写法接近可直接迁移 |
| `≈` | 形似，结构相近但有关键差异 |
| `≠` | 语义不同，写法像但行为不同 |
| `∅` | 该语言没有这个概念（1248 格中有 67 格） |
